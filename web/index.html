Tether
GitHub
QNX OS 8.0 · Developer tooling

Give every QNX process only what it uses.

Tether runs your app on QNX, records the abilities, channels and paths it really touches, writes the smallest security policy that fits, then attacks the app to prove the policy holds.

How it worksTry the CLI


  

    
Observe. Tighten. Enforce. Attack.

    
Built on the QNX security-policy tools that ship with SDP 8.0, so the policy QNX enforces is the one you can read.

    

      
Observe
The app runs its normal workload under secpolgenerate.

      
Tighten
Tether keeps one type's rules, drops what went unused and ranks each grant by risk.

      
Enforce
secpolcompile and secpolpush load it on the target.

      
Attack
An injected exploit runs against the confined app while secpolmonitor logs every refusal.

    

  


  

    
Why it matters
    
      
  • Hand-written QNX policies are slow to write and drift from the code.
    • 
      
  • Running as root hands an exploited bug the whole machine.
    • 
      
  • Tether turns one recorded run into a reviewable, diffable policy file.
    • 
    

    
Use it
pip install git+https://github.com/himanshu748/tether-qnx
tether tighten observed.secpol --type telemetry_t \
  --unused unused.secpol -o telemetry_t.secpol \
  --json run.json
